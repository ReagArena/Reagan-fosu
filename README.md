## 📊 Featured Project Spotlights

### 🛒 1. Walmart Retail Sales & Demand Analytics (M5 Dataset)
* **Objective:** Analyzed $187M+ in retail sales across 10 stores to identify category revenue drivers, regional demand distributions, and item-level demand volatility.
* **Key Deliverables:** Built a Python ETL pipeline to unpivot 3M+ daily records and designed an executive Excel dashboard featuring dynamic PivotTables, KPI cards, and PivotCharts.
* **Impact:** Established a statistical validation framework using the Coefficient of Variation ($\text{CV}$) to segment volatile inventory (`HOBBIES` $\text{CV} = 1.33$) and formulated inventory safety-stock recommendations.
* 🔗 **[Explore Repository & Excel Dashboard](https://github.com/ReganKwakuKonaduFosu/03_Walmart_Retail_Analytics)**
